UN MENSAJITO IMPORTANTE

Incluye index.html y las dos imágenes foto1.png y foto2.png. Aparecerán en la sección de recuerdos cuando se desbloquee la página el 20 de octubre de 2026 a las 00:00, hora peninsular española.

PUBLICAR CON GITHUB PAGES
1. Descomprime el ZIP.
2. Sube index.html, foto1.png y foto2.png juntos a la raíz del repositorio.
3. En GitHub, abre Settings > Pages.
4. Selecciona Deploy from a branch, la rama main y la carpeta /(root). Guarda.
5. Espera a que GitHub Pages publique la web y comparte el enlace que te proporciona.

IMPORTANTE SOBRE PRIVACIDAD
El desbloqueo es visual y se ejecuta en el navegador. No protege el contenido frente a alguien que inspeccione el código antes de la fecha. Para mantener realmente ocultas las fotos y la carta hace falta un backend que controle el acceso.
